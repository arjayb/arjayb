### Digital Barangay — live demo

**[Open the application](https://arjayb.github.io/Digital-Barangay-App/)**

The project demonstrates a complete browser → API → database workflow. Residents can register, authenticate, submit document requests and report concerns; staff can review those records and update their status through a protected admin interface.

## How I build

I use the simplest architecture that fits the product. Earlier projects are intentionally client-side when a backend isn't necessary. Digital Barangay is the next step: a deployed frontend connected to a real Express API, Prisma data layer and PostgreSQL database, with authentication and separate resident/admin workflows.

The repositories document the stack, deployment model, data sources and current limitations rather than presenting prototypes as finished products.
